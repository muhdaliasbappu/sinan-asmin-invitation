# Sinan & Asmin — Wedding Invitation

A resolution-independent SVG invitation with a gold wax seal, six large fan leaves, hinged envelope opening, a deforming cloth knot, self-writing Bismillah, live countdown and family note.

All personal and event details come from the supplied invitation PDF. The Arabic calligraphy is extracted from that PDF. No bitmap artwork, embedded video, canvas, vendor logo, or external font service. Optional music is muted initially.

The page is self-contained. Publish the repository root from `main` with GitHub Pages.
