# Sinan & Asmin — Wedding Invitation

An interactive ivory invitation with a wax-seal envelope, organza ribbon opening, self-writing Bismillah, live countdown, calendar download and family note.

All personal and event details come from the supplied invitation PDF. The Arabic calligraphy is extracted from that PDF. No embedded video, canvas, vendor logo, or external font service. Optional music is muted initially.

The page is self-contained. Publish the repository root from `main` with GitHub Pages.
