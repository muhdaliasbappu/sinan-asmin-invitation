# Sinan & Asmin — Mother of Pearl invitation

Reference: https://www.thedigitalyes.com/demo/mother-of-pearl

The original reference artwork, texture and opening footage are used. The envelope seal is personalized to S & A using an edited monogram tracked onto the original moving seal. The second opening clip retains the original iridescent ribbon animation. Both clips remain 1080 × 1920; compression uses H.264 CRF 18. Decorative textures retain native resolution, encoded as WebP quality 96.

After the ribbon opens, the exact Arabic calligraphy extracted from the supplied PDF reveals right-to-left, followed by “In the name of Allah.” It fades out before the names appear. The invitation text, countdown, calendar download, directions link, telephone link, family note and mute toggle are live HTML interactions. Music starts muted. No video player controls, vendor branding, RSVP, hotel, transport, dress-code or gift sections are included.

All personal details come from New Invitation 02.pdf. Event: Saturday, 19 December 2026, 10:30 AM India Standard Time, Athafy Auditorium, Vallikkad, Muttungal, Vadakara.

Open index.html or serve this folder with any static web server. All fonts, media and textures are local. The single-file version embeds the same assets and is suitable for GitHub Pages.

Monogram assets were edited with the built-in image generation tool. Prompts: “Precisely change ONLY the embossed monogram C & J to S & A, maintaining the same elegant interlocked calligraphy, material, lighting, texture, composition and framing; preserve everything else.” The front edit is composited only inside the original seal’s inner oval; optical-flow and homography tracking follow the seal through the original footage. The footer edit preserves a transparent background.

Responsive checks: 320×568, 390×844, 430×932 and desktop. Browser viewport emulation, not a physical iPhone. Reduced motion skips the videos; media failure falls back to the blessing. Source files: index.html, style.css, script.js. All personal text can be edited in index.html.
