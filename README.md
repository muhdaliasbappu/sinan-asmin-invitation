# Sinan & Asmin — Mother of Pearl invitation

Reference: https://www.thedigitalyes.com/demo/mother-of-pearl

The original reference artwork, texture and opening footage are used. The envelope seal is personalized to S & A using an edited monogram tracked onto the original moving seal. The second opening clip retains the original iridescent ribbon animation. Both clips remain 1080 × 1920; compression uses H.264 CRF 18. Decorative textures retain native resolution, encoded as WebP quality 96.

After the ribbon opens, the exact Arabic calligraphy extracted from the supplied PDF reveals right-to-left, followed by “In the name of Allah.” It fades out before the names appear. The invitation text, countdown, calendar download, directions link, telephone link, family note and mute toggle are live HTML interactions. The cover opens automatically almost immediately (150 ms after the page is parsed), or immediately on a tap. Music is requested with the opening; browser autoplay restrictions may require the first real tap. A subtle synthesized cloth sound follows the ribbon motion. The same mute control silences both. Every reload defaults to sound enabled. Great Vibes is reserved for all appearances of the couple’s names; the location heading uses Cormorant for readability. No video player controls, vendor branding, RSVP, hotel, transport, dress-code or gift sections are included.

Personal details come from New Invitation 02.pdf, with the groom’s address updated at the user’s request to Meethale Peedikayil (H), P.O.: Muthuvadathur. Event: Saturday, 19 December 2026, 10:30 AM India Standard Time, Athafy Auditorium, Vallikkad, Muttungal, Vadakara.

Open index.html or serve this folder with any static web server. All fonts, media and textures are local. The single-file version embeds the same assets and is suitable for GitHub Pages. Keep sinan-asmin-preview.jpg alongside the hosted index.html: its public URL is used by the Open Graph and Twitter sharing metadata for the invitation preview. The 1200 × 630 JPEG uses the pearl artwork, couple’s names, wedding date and venue. Preview metadata appears before the embedded media so link crawlers can read it early.

Monogram assets were edited with the built-in image generation tool. Prompts: “Precisely change ONLY the embossed monogram C & J to S & A, maintaining the same elegant interlocked calligraphy, material, lighting, texture, composition and framing; preserve everything else.” The front edit is composited only inside the original seal’s inner oval; optical-flow and homography tracking follow the seal through the original footage. The footer edit preserves a transparent background.

Responsive checks: 320×568, 390×844, 430×932 and desktop. Browser viewport emulation, not a physical iPhone. Automatic opening, manual timer cancellation, blocked-audio retry, explicit mute and reload defaults are verified by check-opening.cjs. Automatic and tapped opening use the full seal, ribbon, blessing sequence, including with reduced motion enabled. Reduced motion still minimizes decorative CSS transitions. If video playback is refused or stalls, the same full-resolution footage plays as a one-shot animated WebP; it never skips directly to the blessing. The fallback downloads only when needed. If both formats fail to load, a retry button is shown. Music is requested at opening, but browser sound policies may still require a real tap. Source files: index.html, style.css, script.js. All personal text can be edited in index.html.
